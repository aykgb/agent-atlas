# 远端面板：链接主机 + 对齐「同步」

来源：2026-09-28 用户需求。远端行有两个问题：`同步` 按钮位置随状态文字长度浮动，多台之间对不齐；主机名只是文本，要访问远端页面得手动复制地址。

## 现状与落点

- 前端 `renderRemotes`（static/app.js:54-76）拼每行 HTML：`启用` 复选框、`<b>主机:端口</b>`、能力标签、状态、`同步`、`移除`。
- `同步` 与 `移除` 都是 `.text-button`，其 `margin-left:auto`（style.css:1）在 flex 行内对两处自动外边距平分剩余空间，于是 `同步` 落在中段且位置随状态文字宽度变化。
- 主机为纯文本，无跳转入口。远端服务本身就是 HTTP 页面（同一版本），`http://主机:端口/` 可直接打开。

## 方案

- 主机改为 `<a class="remote-host">`，`href` 与 `target="_blank" rel="noopener"`，点击在新标签打开远端页面。
- 把 `同步`、`移除` 收进 `.remote-actions` 右侧按钮组（`margin-left:auto`），组内按钮去掉自动外边距；两个按钮宽度固定，组右对齐即 `同步` 列对齐。
- 组内保持 `同步` 在前、`移除` 在后；停用行不渲染 `同步`，只留 `移除`（仍靠右对齐）。

## 验收

1. 多台远端行（含位数不同的「N 轮已同步」）的 `同步` 左边缘对齐，`移除` 右边缘对齐。
2. 点击主机名在新标签打开 `http://主机:端口/`；停用行同样可点。
3. `unittest` + `node --check` 通过。

## 实测

- `node --check static/app.js` 通过。
- 无头 Chrome 按真实行结构截图（1200×420）：4 行（160/56/1,684 轮 + 停用行）`同步` 左边缘同列、`移除` 右对齐；主机名带下划线链接样式。
- `unittest` 44 项：43 通过，`test_index_suffix_keys_by_resolved_home` 失败；该失败与本次无关，`git stash` 后在未改动树上同样失败（macOS `/tmp` 为 `/private/tmp` 符号链接导致哈希不同）。

## 非目标

- 不改后端接口、不改同步逻辑、不加「打开」按钮或图标。
- 不校验远端可达性，跳转失败由浏览器承担。
