# 词频：只看中文视图过滤（隐藏数字与英文）

来源：2026-09-19 用户需求。词频低频区被数字与英文词淹没（如截图 `00000…`、`039s`、`openssh`），需要一键隐藏；启用深色、停用浅色，色彩布局与整体协调。初版为「排除数字」「排除英文」双开关，用户反馈合并为一个开关。

## 现状与落点

- 后端 `/api/words`（stats_server.py:660-686）：合并本机与远端后排序取前 `limit` 个，无类别过滤。
- 前端词频面板（static/index.html:27）：`exclude-box` 内为持久排除（写入 `words-exclude.txt`）；`word-controls` 为排序与数量。
- 样式变量（static/style.css）：`--ink:#202d3e`、`--line:#e5e9ef`、`--soft:#edf2ff`；按钮默认白底细边框。

## 方案

- 后端：`/api/words` 支持 `hide_digits=1` / `hide_english=1`（仅 `1` 生效，其余视为关闭）：
  - `hide_digits`：隐藏含 `\d` 的词；`hide_english`：隐藏含 `[a-zA-Z]` 的词。
  - 在合并后、排序取 `limit` 前过滤，两者为“或”关系；默认关闭，现有行为不变；远端合并同样成立。
  - 仅影响展示，不写入 `words-exclude.txt`，不影响搜索。
- 前端：在 `exclude-box` 末尾加单个「只看中文」开关（`aria-pressed`），开启时同时传 `hide_digits=1&hide_english=1`（复用后端两参数，不新增接口参数）：
  - 布局：沿用 `exclude-box` 的 flex wrap 行内排列，与输入框同高，不新增形状与尺寸。
  - 色彩：停用沿用默认按钮（白底、`--line` 边框）；启用深色（`--ink` 底白字，hover `#33415a`），与 logo / tip 的深色呼应。
  - 点击切换后重新请求 `/api/words`；重置筛选时一并关闭；远端只读下仍可用（视图过滤，非写操作）。
- 口径：开关开启 = 隐藏所有含数字或英文字母的词（如 `debug3`、`039s`、`chrome`），仅剩纯中文等无数字无英文的词。

## 验收

1. 默认关闭，与现状一致。
2. 开启只看中文：含数字或英文字母的词消失，仅剩纯中文等词；远端合并场景同样成立。
3. 开关启用深色、停用浅色；重置筛选恢复关闭。
4. `unittest` + `node --check` 通过。

## 非目标

- 不改分词与停用词默认口径（单字、纯数字过滤不变）。
- 不持久化开关状态、不写入排除文件。
- 不新增排序键与 limit 语义。
