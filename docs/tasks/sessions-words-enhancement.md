# 会话展示与输入词频功能优化增强

来源：结合全库 4 源（5,750 轮 / 1,480 会话）与 UI 交互审查，解决会话列表只见 UUID 不见主题、缺少模型/日期/来源与多维度排序、会话详情缺少 Token 构成与长会话浏览工具、以及词频易被单轮粘贴高频词霸榜、形态与治理较弱的问题，并保持 `SCHEMA_VERSION = 5` 与既有远端索引兼容。

## 目标与改动范围

### 1. 「会话」展示优化增强

- **后端 `/api/sessions`（`stats_server.py`）**：
  - 全量接入全局与页内筛选：`agent`、`model`（大小写不敏感，匹配会话内出现过的模型）、`start` / `end`（按轮次日期范围过滤含该时段活动的会话）、`source`（按来源主机 `key` 过滤）以及 `q`（同时匹配会话 ID 子串与首条用户输入主题摘要，保持 `q` 大小写不敏感）。
  - 新增排序维度 `sort`：`created`（默认，创建时间倒序）、`active`（最近活跃 `last` 倒序）、`tokens`（Token 总量倒序，无用量列排末尾）、`turns`（轮次数倒序）。
  - 返回增强字段：每行保留全部既有字段并补充首轮输入主题摘要 `topic`、去重合并后的模型列表 `models`；顶层补充汇总统计 `summary`（总会话数、总轮次、已统计 Token 总量）。
- **后端 `/api/session`（`stats_server.py`）**：
  - 保留既有字段，额外返回会话级 `usage`（与列表同口径，无记录或未勾选用量时为 `None`）、`models`（会话出现过的模型列表），以及每轮的 `input_len`（输入字数）与 `part_count`（输出段数）。
- **前端列表与详情（`static/index.html`、`static/app.js`、`static/style.css`）**：
  - 全局筛选栏在 `sessions` 页保持「模型」与「日期范围」可见可用，实现四页共用筛选。
  - 列表工具栏新增来源选择（多源时显示）、排序选择器与统计汇总摘要；过滤框提示兼顾会话 ID 与首句主题，命中时高亮 `<mark>`；列表卡片展示 Agent、来源、会话 ID、模型标签、轮次数、Token 用量（悬浮明细）、起止时间与首条用户输入主题摘要。
  - 会话详情顶部展示复制 Session ID 按钮、模型标签组与紧凑型会话 Token 构成条/明细；新增详情工具栏（轮内快速过滤 `#detailFilter`、正序/倒序切换、跳转首轮/末轮、分批限流「全部展开」、一键导出 Markdown）；单轮卡片标注 `#序号`、`模型`、`时间戳`、`输入字数` 与 `响应段数`。
  - 列表新增 `ssource` / `ssort` 与日期参数同步到 URL Hash。

### 2. 「输入词频」功能优化增强

- **后端 `/api/meta` 与 `/api/words`（`stats_server.py`）**：
  - `/api/meta` 补充 `words_sources`（勾选了 `words` 的启用来源列表）。
  - `/api/words` 新增 `source`（来源过滤）、`sort`（`count` 总次数 / `turns` 覆盖轮次 / `avg` 轮均次数，配合 `order=desc|asc`）、`kind`（`all` 全部 / `zh` 仅中文 / `code` 英文与代码词，同时保留旧 `hide_digits`/`hide_english` 参数兼容）、`min_turns`（最小覆盖轮次去噪门槛）及 `q`（词条子串检索）。
  - 每个词条补充 `avg`（轮均出现次数）、`share`（占当前筛选词频总次数的百分比）与 `turn_rate`（覆盖轮次占比 %）；顶层补充 `summary`（`unique_terms`、`total_count`、`scoped_turns`、`max_turns`）。
- **前端可视化、去噪与治理（`static/index.html`、`static/app.js`、`static/style.css`）**：
  - 头部新增 4 格汇总指标卡（不同词条、总出现次数、覆盖人工轮次、Top 1 热点词）与时间快捷预设按钮（近 7 天 / 近 30 天 / 本月 / 全部）。
  - 新增视图切换：清晰加宽的「排行条形图」（按主排序字段拉伸进度条、标排名序号与双指标、复用全局 `#tip` 悬浮卡显示详细指标）↔「词云分布」（按对数/平方根映射字号与权重色阶，支持悬浮详情、点击检索、右上角快捷排除）。
  - 控制栏整合：排序字段（次数/轮次/轮均）+ 方向（高→低/低→高）、词性分段（全部 / 仅中文 / 英文与代码）、最少轮次去噪门槛（不限 / ≥2 / ≥3 / ≥5 / ≥10 轮）、来源主机下拉、词条检索框、展示条数上限（前 20/40/100/200 词）。
  - 排除词体验增强：点词条 `×` 后展示一键撤销横幅（「已排除 xxx · 撤销」），超过 10 个排除词时默认折叠可一键展开全部或全部恢复；点击高频词跳转到会话搜索时一并继承来源过滤；新控件状态完整同步 URL Hash（兼顾旧 `zh=1`）与「重置筛选」。
