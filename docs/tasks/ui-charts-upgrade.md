# 前端可视化、图表与交互界面升级

来源：2026-11-14 全仓 review。实测近 14 天缓存读取（`cr`）占总 token 的 96.7%，单一 `total` 口径掩盖了新增输入与生成输出趋势；同时图表响应式布局、交互联动、表格操作与样式可维护性均有较大提升空间。

## 目标与改动范围

### 1. 用量图表可视化升级（`static/index.html`、`static/app.js`、`static/style.css`）
- **多指标维度切换**：增加指标切换（`总用量` / `非缓存 (新增+输出)` / `模型输出` / `新增输入` / `调用次数`），同步驱动趋势柱状图、环形占比图与 Agent / 模型排名榜。
- **Token 构成占比条**：在 4 张概览指标卡下增加水平构成比例条（新增输入 / 缓存写入 / 缓存读取 / 模型输出），并在指标卡副标题补充缓存命中率 `cr / (new + cr)`、日均/周期均值与输出占非缓存比例。
- **堆叠柱状图升级**：
  - 固定左侧 Y 轴刻度，绘图区按容器宽度自适应且超宽横向滚动（解决桌面宽屏两侧留白、长周期 Y 轴滚出视口问题）。
  - 增加趋势模式切换：`按分组堆叠` / `100% 占比` / `按 Token 构成`。
  - 增加周期均值参考虚线；X 轴跨年保留年份并按密度自动抽稀；周视图提示完整起止日期。
  - Tooltip 展示该周期总计与分组明细，并附下钻提示；支持键盘 `Enter`/`Space` 触发下钻；极小柱段增加可悬停热区。
- **环形占比图与图例联动**：
  - 中心圆默认显示当前指标总值，悬停或聚焦扇区/图例时动态展示该项名称、数值与占比。
  - 优化调色板并把「其他」固定为中性浅灰；图例支持悬停高亮双图联动、点击切换系列显隐，以及点击「其他」展开内部明细。
- **排名榜与明细表交互**：
  - 点击 Agent / 模型排名行可快速切换筛选（再次点击取消）。
  - 明细表支持点击任意列头排序（升降序箭头指示）、新增「占比」列与底部「合计」汇总行、支持精确/缩写数字切换及点击行筛选。

### 2. 前端交互体验与工程化（`static/index.html`、`static/app.js`、`static/style.css`）
- **用量页开放自定义日期**：释放 `/api/usage` 已有的 `start`/`end` 能力，提供快捷预设（今天 / 近 7 天 / 近 14 天 / 近 30 天 / 本月 / 自定义日期）。
- **URL Hash 状态同步**：同步当前 tab、筛选、指标、分组、分页与已打开会话到 `location.hash`，支持刷新保持与浏览器前进/后退。
- **搜索、会话与词频体验**：
  - 搜索卡片展示来源标签（本机 / 远端备注名）；轮次内增加「复制」与「全部展开/收起」；输出段类型标签用 Flex 布局并按类别区分色标。
  - 词频双列改按纵向顺序排布（左列 1..N/2，右列续接），补充统计摘要。
  - 远端面板折叠摘要在存在同步失败时直接标红提示。
- **样式规范与深色模式**：展开格式化原本压缩成单行的 `static/style.css`，补充 `prefers-color-scheme: dark` 及页头手动亮/暗主题切换。

## 验收

1. 指标切换（总用量 / 非缓存 / 输出 / 新增输入 / 调用次数）下指标卡、趋势图、环形图与排名榜数值逐项一致。
2. 桌面宽屏（1440px）柱状图无异常留白、长周期横向滚动时 Y 轴固定；窄屏（390px）无横向溢出、布局不乱；深/浅色主题渲染清晰。
3. 明细表可按任意列排序、含合计行；环形图中心随悬停联动；词频纵列顺序正确；自定义日期、URL Hash 刷新保持、复制与全部展开可用。
4. `node --check static/app.js`、`unittest` 与无头 Chrome 冒烟全部通过且无控制台报错。
