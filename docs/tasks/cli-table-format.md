# CLI 表格输出优化：stats-today.py 对齐表格

来源：2026-09-21 用户需求。`stats-today.py` 的两个表格（多日每日表、agent×模型明细表）改为对齐表格样式：`|` 分列、表头下虚线分隔、表尾 `─` 收尾线，数字列右对齐、文本列左对齐。

## 现状与落点

- 现状：两个表用固定/计算宽度的 f-string 拼接，无列分隔符与边框。
- 落点：新增 `render_table(headers, rows, aligns)` 统一渲染；两个表复用。

## 口径

- 只改展示，不改数据：聚合逻辑、字段、数值、`--json` 输出完全不变。
- 对齐：`date`/`agent / model` 列左对齐，其余数值列右对齐；单元格用千分位逗号。
- 样式：列间 ` | `；表头下一行为每列等宽 `-`；表尾一行 `─`（跨整表宽）。

## 实现要点

- `stats-today.py`：新增 `render_table`；多日表与明细表改为「构造 headers + 已格式化 rows + aligns → render_table」；`total` 汇总行并入 rows 末行。
- 表格内容均为 ASCII（agent/模型名、数字），无 CJK 宽度问题，`len()` 对齐即可。

## 验收

1. 无参 / `--week` / 指定单日 / `--json` 输出数值与改前一致（`--json` 逐字节相同）。
2. 两表列对齐、`|` 分隔、表头虚线、表尾 `─` 线齐全；窄列不越界。
3. `unittest` 与 `node --check` 全过（前端不受影响）。

## 实测（2026-09-21）

- 单日 / `--days 3`：两表 `|` 分列、表头虚线、表尾 `─` 线齐全，数字右对齐；单日各行数值与改前逐格一致（如 total 28,066,573）。
- `--json` 形状不变（无 `warnings`，字段齐全）；`unittest` 34 项 + `node --check` 全过。

## 非目标

- 不改 `--json`；不改 server / 前端；不引入表格依赖（纯标准库）。
